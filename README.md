Сайт упаковщик файлов.
🖼 Режим «Изображение»
Загрузка фото перетаскиванием, через выбор файла или вставкой из буфера (Ctrl+V)
Конвертация форматов: PNG, JPG, WEBP, BMP
Настройка качества сжатия (для JPG/WEBP, ползунок 10–100%)
Изменение размера (ширина × высота) с блокировкой пропорций 🔒 и сбросом к исходным
Переименование файла кликом по названию
Скачивание результата и копирование картинки в буфер обмена
📄 Режим «Текст и код»
Поддержка: TXT, HTML, JS, CSS, JSON, MD, CSV, XML
Предпросмотр содержимого (первые 3000 символов)
Встроенный редактор — можно изменить текст перед сохранением
Смена расширения файла (например, .txt → .json)
Вставка текста прямо из буфера обмена
Скачивание и копирование текста
📦 Режим «Папка»
Добавление файлов и целых папок (drag&drop с сохранением структуры, кнопки «Файлы»/«Папку»)
Массовая конвертация всех фото в один формат (PNG/JPG/WEBP) с настройкой качества
Переименование отдельных файлов, сортировка (по имени/размеру), удаление, защита от случайной очистки («Точно очистить?»)
Скачивание всего одним ZIP-архивом (JSZip, сжатие DEFLATE)
⚙️ Общие возможности
Тёмная/светлая тема с запоминанием выбора
Тосты-уведомления и анимированный оверлей результата (успех/ошибка)
Запоминание последнего открытого режима (localStorage)
PWA: manifest + Service Worker (sw.js) — офлайн-работа и установка как приложение
Работает офлайн, файлы никуда не отправляются — вся обработка локально
